# Tether

A native macOS terminal workspace for Claude Code, with an iPhone companion
that mirrors sessions, pushes a notification when Claude needs you, and lets
you start work from your phone.

Status: phase 1 (terminal workspace) in progress, unverified on a real Mac yet. See [docs/PLAN.md](docs/PLAN.md).
